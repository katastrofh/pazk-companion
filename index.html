How to use this companion

Beginner mode

Read each chapter’s Overview and Understand tabs first. Ignore implementation details until the mental model is clear.

  • Ask: what is the verifier checking?
  • Ask: where does randomness enter?
  • Ask: what can a cheating prover fake?

Builder mode

Use Implement, Build planner, and toy labs. Build insecure educational versions first, then replace primitives with audited libraries.

  • Write data structures.
  • Write protocol transcript.
  • Write negative tests.

Review mode

Use Flashcards, Quiz mode, and section checkboxes. Export progress before publishing or moving devices.

  • Mark sections done.
  • Save notes per chapter.
  • Export Markdown for a study log.
